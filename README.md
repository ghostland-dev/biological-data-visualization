# BioViz

Biological and genomics data visualisation dashboard.

## Features

- Genomics views
- Visualisations and export

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/biological-data-visualization.git
cd biological-data-visualization
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
